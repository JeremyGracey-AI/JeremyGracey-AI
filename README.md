# Jeremy Gracey

AI/ML engineer and technical founder in Seattle, WA. I build clinical AI and agent infrastructure with a bias toward provenance: answers that cite the patient record, the textbook page, or the decision log that produced them.

## What I build

- Clinical decision support on open standards: SMART on FHIR, transparent RAG, and citations that trace back to patient data and clinical sources.
- LLM orchestration: MCP servers, multi-model deliberation, agent pipelines, and eval harnesses that keep them honest.
- Local-first tooling: monitoring dashboards and menu bar apps for infrastructure I run myself.

## Featured projects

- [clinical-ai-agent](https://github.com/JeremyGracey-AI/clinical-ai-agent): Patient-grounded clinical decision support on SMART on FHIR. Five-agent pipeline with dual citations and a reproducible eval harness.
- [llm-council-mcp](https://github.com/JeremyGracey-AI/llm-council-mcp): Multi-model LLM council with three-stage deliberation over OpenRouter, exposed as an MCP server for Claude Code.
- [p2pool-monitor](https://github.com/JeremyGracey-AI/p2pool-monitor): Local-first macOS menu bar app and web dashboard for a self-hosted Monero P2Pool mining stack. The wallet never leaves the machine.
- [Hospital-Readmission-Prediction-Model](https://github.com/JeremyGracey-AI/Hospital-Readmission-Prediction-Model): Full ML pipeline for 30-day readmission risk, with SHAP interpretability and demographic fairness analysis.
- [rag-healthcare-ai](https://github.com/JeremyGracey-AI/rag-healthcare-ai): Local RAG over the Merck Manual with Mistral-7B, ChromaDB, and MiniLM embeddings.
- [Agents-League-Hackathon-Compass-BlackBox-IQ](https://github.com/JeremyGracey-AI/Agents-League-Hackathon-Compass-BlackBox-IQ): Flight recorder for autonomous agents. Git-backed memory, decision records, and a skill forge over MCP. Agents League @ AI Skills Fest 2026.

Also worth a look: [provenance](https://github.com/JeremyGracey-AI/provenance), a LangGraph RAG that verifies every claim against the textbook page image that supports it.

## Stack

Python and TypeScript. Claude API, MCP, LangGraph, FastAPI, RAG and evals. FHIR and SMART on FHIR on the clinical side. Azure and Vercel for deployment.
