# Jeremy Gracey

I build AI agents that can prove their work. Clinical decision support, agent
memory systems, and customer-facing products — all with citations, decision
logs, and evals behind them.

## What I build

- **Agent infrastructure**: MCP servers, multi-model deliberation, governed
  agent memory, and eval harnesses — the plumbing that makes autonomous
  agents accountable.
- **Clinical AI on open standards**: SMART on FHIR, transparent RAG, and dual
  citations that trace every answer back to patient data and clinical sources.
- **Production AI products**: customer-facing agents for real businesses —
  booking, triage, and operations — deployed and in use, not just demoed.
- **Local-first tooling**: monitoring dashboards and menu bar apps for
  infrastructure I run myself.
